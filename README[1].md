# SunSync Complete Website

## Publish with GitHub Pages
1. Create a public GitHub repository, e.g. `sunsync-website`.
2. Upload `index.html` to the repository root.
3. Go to Settings -> Pages.
4. Under Build and deployment choose Deploy from a branch.
5. Select `main` and `/ (root)`.
6. Click Save.
7. Wait for GitHub Pages to publish the site.

## Before publishing
Replace `your-email@example.com` in `index.html` with your actual startup contact email.

## Important
Dashboard measurements are simulated demo data. A real system needs hardware sensors, a microcontroller/firmware, safe motor control, and a backend/API or other data connection to display actual measurements.
